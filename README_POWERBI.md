Power BI Dashboard

Retail Business Performance & Profitability Analysis

An interactive Power BI dashboard designed to analyze retail sales, profitability, product performance, category performance, regional performance, and business trends.

Dashboard Objective

The dashboard provides a consolidated view of retail business performance and helps identify:

- Overall sales and profit performance
- Profit margin and order performance
- Category-wise sales contribution
- Regional sales distribution
- Sub-category profitability
- Top profitable products
- Business performance across different time periods
- Key areas for profitability optimization

Dashboard KPIs

The dashboard includes the following key performance indicators:

- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Average Order Value

Main Visualizations

- Sales & Profit Trend
- Sales by Category
- Sales by Region
- Profit Margin by Sub-Category
- Top 10 Products by Profit
- Key Business Insights

Interactive Filters

Users can analyze the dashboard using:

- Region
- Segment
- Category
- Order Date

Tools & Technologies

- Power BI
- DAX
- Power Query
- Python
- SQL
- CSV

Power BI File

The main dashboard file is:

"final.pbix"

Open the file using Microsoft Power BI Desktop.

Dashboard Theme

The dashboard uses a professional blue and green visual theme focused on profitability intelligence.
